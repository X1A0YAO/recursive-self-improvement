## 四、科学结论

### 4.1 主问题回答

**Q1（能否通过自主修改提升真实任务准确率？）**：否（本设定下）。
Agent 的两次真实修改均降 3.3pp；全部编辑被回滚后 B≡D。

**Q3（Agent 修改是否优于随机？）**：明确否——C 组随机方向反而 +2.8pp
（虽不显著）。Agent 的"诊断驱动"选点（L33 attention）比随机选点
（L20 k_proj）更差：**4B 模型的权重诊断信号（|z| 异常 + 激活统计）
与任务能力无可靠关联，甚至负相关**——这与 Phase 3 EXP2 的
“天然 z 异常层不是缺陷层”结论完全一致。

**Q7（失败归因）**：三层复合：
- a) **空间窄**（F2/F3）：0.05 预算下随机搜索 8 次无显著正向
- b) **Agent 信号无效**（F1）：诊断信号驱动的选点系统性偏差
- c) **协议遵循缺陷**：6 轮中 3 轮浪费在格式错误（预算规则/张量命名），
  有效尝试仅 2 次

### 4.2 与 Phase 1-3 的合并图景

四阶段完整证据链现在闭合：
1. Phase 1-2：隐蔽缺陷的行为后果与统计可见性双双缺失
2. Phase 3：原始权重读取分辨率错配（0.1% 覆盖）+ 观察幻觉
3. Phase 4：即使绕过诊断（真实任务反馈替代缺陷定位），Agent 的
   干预选择仍不优于随机——**权重空间干预在 4B 规模缺乏可用的
   "能力 → 参数"映射信号**，无论来源（统计、激活、还是任务反馈）

**总命题（Phase 1-4 合并）**：Qwen3-4B 通过工具介导的权重检查与
修改实现自我改进的链条，在**每一环**（缺陷可见性/定位/修复/能力提升）
都存在超过该模型规模的障碍；每一环的失败都有量化机理。

### 4.3 C 组副发现（诚实记录）

随机编辑 +2.8pp（p=0.30）虽不显著，但方向为正；E 组 8 方向中 5 个
非负。这提示**极小幅度全局 scale 扰动**可能存在弱正效应
（类似轻量正则化）——值得后续用更大样本（n≥600）验证，但超出
本预注册范围（记录为 future work，不做声明）。

## 五、工程审计（全程问题清单）

| 问题 | 影响 | 修复 |
|---|---|---|
| v1 单进程 20h 死循环+驱动劣化 | 首日全损 | v2 子进程隔离 |
| `extract_tool_call` 嵌套 JSON 正则缺陷 | **全部历史实验的 decide 解析失败**（B2a/B2b/P3 的"提案悬崖"部分源于此！） | 平衡括号扫描重写 |

意味着此前所有"模型不提交决定"的结论需要部分重新归因——
模型可能多次提交了有效 decide 但解析器静默丢弃。
