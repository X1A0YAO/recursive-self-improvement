## 实验一：18 格扰动矩阵（预注册 §2-3）

### 阶段 A 筛查（0/18 过线 → S1' 主判定依据）

最强格 activity_zero_512（L26 单层）：logprob Δ = -2.02（资格线 -3.0），
quick-20 零退化。18 格全景见 results/matrix_screen_full.json。

**矩阵内部结构**（select × op 交叉平均 logprob Δ）：
- activity/zero：-0.82 (k128) / -2.02 (k512) / +0.37 (k2048) —— 最强但非单调
- norm/zero：+0.64 / +0.55 / -0.35 —— 无效
- 低秩叠加（两种 select）：全部 |Δ|<1 —— 随机方向无效（Phase 1 结论重现）

### 阶段 B 上界探测（探索性，AMENDMENT1 D2）

单层最强格 DS-120 全量：**0.808 vs V0 0.783（+2.5pp"提升"）**，
McNemar worse=1/better=4 p=0.969 —— 无退化。

**方法论发现（本 Phase 最重要的单条）**：teacher-forced logprob Δ=-2.02 的
扰动在自由生成行为上是 +2.5pp。两种测量根本不在测同一个东西：
前者测"给定金标的条件概率"，后者测"贪心解码的实际轨迹"。后续任何
缺陷工程必须直接用行为测量筛选。

## 综合机理图景

Phase 1+2 合并后的传导链断裂点定位：

```
权重扰动 ──(实验一: 需跨过冗余补偿阈值, 单层~21%神经元不够)──▶ 行为改变
     │
     ├─(实验二: 统计量被层间自然变异淹没, z-score方向甚至反转)──▶ 可检测性 ✗
     │
     └─(实验三/四: 4%搜索空间覆盖 + 修复值≈随机)──▶ 自主修复 ✗
```

**核心发现**：Qwen3-4B 的参数-行为传导链在"隐蔽缺陷"区间存在**三重
断裂**（行为冗余、统计隐形、修复无信息），且互不独立——统计隐形使
定位不可能，定位不可能使修复无的放矢，而行为冗余使这一切"无所谓"
（缺陷本身无害）。RSI 在此规模/此缺陷类上的证据链无法闭合。
