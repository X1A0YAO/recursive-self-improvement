## 1. 方法学

### 1.1 top-activity 神经元选择（预注册 §0）

第 $\ell$ 层 MLP（SwiGLU）神经元 $i$ 对 token $x_t$ 的输出为
$h_i(x_t) = \mathrm{silu}(g_i(x_t)) \cdot u_i(x_t)$（$g_i, u_i$ 为 gate_proj / up_proj 第 $i$ 行线性函数）。**任务集活跃度**定义：

$$a_i = \frac{1}{|\mathcal{P}|} \sum_{x \in \mathcal{P}} \frac{1}{T_x} \sum_{t=1}^{T_x} |h_i(x_t)|$$

- 参照集 $\mathcal{P}$ = optimization split 全部 25 条 math 题 prompt（仅 prompt、teacher-forced 单次前向；不含 validation/test，保持 split 隔离）
- top-activity-k = $a_i$ 降序前 k；对照组 top-norm-k = up_proj 行范数降序前 k
- 用 $|h|$ 而非 $|u|$：$h_i \equiv 0$ 当且仅当该神经元对该层输出零贡献；$|u_i|$ 大但 silu(g_i)≈0 是"待命"神经元——审计（AUDIT_REPORT 机理 1/2）已证明 top-norm 是三种选择策略中最差的
- 实现提为公共模块 `scripts/neuron_activity.py`（与 audit_baseline2 定义一致）

### 1.2 DS-120 构成与功效分析（预注册 §1）

配对二项功效推导：目标检出 p_b（V0 正确率）=0.80 时 δ=0.10 退化；不一致率 ψ≈0.15、退化:改善=4:1（审计 E 项方向偏置），单侧 α=0.05、功率 0.80 → n≈105，加 15% 余量 → **n=120**。构成（新采集，seed=20261105，与既有 split 严格无重叠：prompt 精确匹配 + 8-gram 近重复过滤）：

| 任务组 | n | 来源 |
|---|---|---|
| GSM8K math | 50 | openai/gsm8k test 新抽样 |
| IFEval-style 指令 | 20 | 本地构造（长度/格式/关键词约束） |
| 逻辑 | 25 | 本地构造（家族/排序/蕴含） |
| 重复变换 | 25 | 本地构造 |

评分与 baseline 同一 evaluate.py（官方 IFEval 检查器、#### 提取、截断=0）；贪心解码、max_new_tokens=768、batch 4。**DS-120 只用于缺陷/修复的行为测量**；模型选择与自诊引导仍只用 optimization split。

### 1.3 两阶段 screen→confirm 与 Holm 校正（预注册 §2-3）

- 阶段 A（screen）：18 格全扫（选择 {top-norm, top-activity} × 操作 {zero, scale×0.5, lowrank+} × k {128, 512, 2048}，层位固定 L26 up_proj），仅测 logprob Δ（optimization 25 math gold 解）与 quick-20（16 math+4 logic），**不做推断性判定、不消耗 α**；资格线：logprob Δ ≤ -3.0 或 quick-20 退化 ≥3 题
- 阶段 B（confirm）：资格格（预期 ≤6）跑 DS-120 全量 + McNemar 精确检验（单侧，退化方向）
- **Holm 规则**：族=确认集 m 格；原始 p 升序 p(1)...p(m)，p(i) 与 α/(m-i+1) 依次比较，首个不满足者及其后全部不显著；报告每格原始 p、Holm 调整 p、是否通过；敏感性另报 BH-q（FDR），与 Holm 不一致时以 Holm 为准
- 标准缺陷选定：Holm 通过且效应量 10-40pp 的格子中取行为退化中位数最接近 20pp 者；若全部不通过 → 如实报告"无可控缺陷配置"负结果，主线终止

### 1.4 检测器与泛化协议（预注册 §4）

- 用实验一选定的标准缺陷配置，seed 扰动重抽 5 实例 s1-s5：随机重选病灶层（26 个中后层均匀抽 3 层）+ 基于新层重算 top-activity + 重新注入
- 检测器运行前冻结于 `scripts/audit_defect.py`：D1 z-score（每投影类型内跨层 |z|>2.5 于 mean/std/l2）、D2 行范数分布 KS（病灶层 vs 同投影全部层，Bonferroni 0.05/36）、D3 零指纹（zero_rows>0，仅记录不计入 AUC——审计已证明其依赖注入方式）
- AUC 协议：每实例 252 单元（36 层 × 7 投影）全参与，标签=是否真实病灶，分数=各检测器最大异常分；D1/D2 各算 AUC，D3 单独报检出/假阳
- **泛化标准：5 实例中 ≥4 个 D1-or-D2 AUC≥0.85 或 D3 全检出**（实例内任一检测器达标即可）；基线对照：同一检测器跑健康 V0，记录假阳性（应无检出）

### 1.5 修复闭环四臂（预注册 §6，全部在标准缺陷 s1 上）

| 臂 | 定位 | 修复值来源 | 意义 |
|---|---|---|---|
| A1 agent | Agent 自诊+提案 | Agent propose_edit | 完整自主链 |
| A2 oracle-loc + agent-repair | 密封记录告知层与行集 | Agent propose_edit | 拆解：定位误差归零后，修复值生成能力如何 |
| A3 oracle 全知 | 密封记录 | V0 原值恢复 | 上界 |
| A4 random-edit | 随机层+随机行同预算 | 与 Agent 提案同分布 | 下界 |

- A2 协议：实验人员外注入"病灶在层 X up_proj 行集 R"（由密封记录导出），Agent 仍只见 JSON 工具，须 propose_edit 凭"健康统计该是什么样"的推理生成具体修复值，不允许直接读 V0
- 各臂流程：注入 → 诊断/定位 → 提案 → Weight Editor 应用 → V1-x → DS-120 全量
- 判定：S4' = A1 或 A2 相对缺陷模型恢复 ≥5pp 且 McNemar p<0.10（Holm 校正 2 个比较）；S5' = 获胜臂 test split（79 题）相对 V0 退化 <5pp 且不显著；A2−A1 差值 = 定位误差的代价，A3−A2 差值 = 修复值质量的代价
