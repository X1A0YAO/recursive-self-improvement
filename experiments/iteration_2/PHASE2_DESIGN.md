# Phase 2 实验设计（基于审计结论重新设计）

- 日期：2026-11-05 11:30
- 前置输入：`AUDIT_REPORT.md`（同目录）——本设计的每一条都对应审计发现
- 状态：设计稿，待用户批准后预注册执行

## 0. Phase 2 的目标重定位

Phase 1 + 审计确立的事实：
1. 参数→行为的传导链在两环断掉：(a) 统计可见性（自然变异淹没 4% 级信号）；
   (b) 干预选择性（top-norm ≠ 功能重要）
2. 行为级显著性需要配对检验 + 全量评测，不能靠均值差
3. 4B 模型自身用通用统计工具做诊断，连"正确否定"都做不到有据可依

Phase 2 的核心问题随之变为（比 Phase 1 的"修复缺陷"更根本）：

> **RQ1（可见性）**：什么类别的参数扰动能在"不毁灭模型"的前提下产生
>   统计上可检出、行为上可测量的效应？
> **RQ2（选择性）**：基于功能度量（而非范数）选择干预目标，
>   传导效率能提高多少？
> **RQ3（自主性）**：把 RQ1/RQ2 的工具交给模型自己，它能否学会
>   "用对工具查对地方"？（Phase 1 只证明它会调用工具，但不会选择策略）

## 1. 实验一：扰动类型矩阵（回答 RQ1+RQ2，纯离线，无需 Agent）

在固定的 1-2 个层（沿用 L26 up_proj + 新增 L26 down_proj）上，系统对比
**2（选择策略：top-norm vs top-activity）× 3（操作：置零/缩放0.5/加低秩噪声）
× 3（强度 k=128/512/2048）** = 18 个单元格（每格 8 题数学 teacher-forced
logprob + 20 题 quick 行为），建立"扰动→效应"传导表。

- 预测（来自审计数据）：top-activity+置零最强；top-norm 类全弱
- 产出：`results/perturbation_matrix.json` + 传导效率热力图
- 通过标准：找到 ≥1 个单元格 logprob Δ ≤ -5.0 且行为 McNemar p<0.05
  且退化 10-40pp——该配置成为 Phase 2 后续实验的标准缺陷
- 预算：18 格 × (8×logprob + 20×生成) ≈ 6-8 小时 GPU

## 2. 实验二：可见性审计协议（回答 RQ1 的检测侧）

对实验一产出的"标准缺陷"运行检测审计（写死为 `scripts/audit_defect.py`）：
- z-score（mean/std/l2/quantiles）跨层召回
- 行范数分布的 KS 检验 vs 健康层
- 激活统计对比（病灶层 vs 邻层的神经元贡献分布漂移）
- **通过标准：至少一种无监督检测 AUC>0.9**（不依赖"精确零"指纹）
- 若不通过：缺陷虽然"行为可见"但"统计隐形"——本身就是关键发现
  （诊断协议必须包含激活探测，不能只靠权重统计）

## 3. 实验三：结构化自诊 v2（回答 RQ3，Agent 实验）

吸取 Phase 1 教训（模型不会自主选择搜索策略），诊断协议升级：

1. **工具升级**（仍 JSON-only，不执行任意代码）：
   - `compare_tensor_stats` 增加 `metric: [mean,std,l2,zero_rows,ks_vs_neighbors]`
   - 新增 `compare_activations`（跨层神经元贡献分布，基于一小批 optimization 题）
   - 新增 `budget_report`（告知剩余轮次，缓解 Phase 1 的"前 5 层死循环"）
2. **策略脚手架**（两臂对照）：
   - A 臂（自由）：同 Phase 1 提示
   - B 臂（引导）：提示中给出"先 list_layers → 逐投影分层扫描 → 优先中后层"
     的策略清单（引导是否有效本身是实验对象）
3. **评分**：定位命中率（查询/提案是否命中真实病灶层）× 预算效率
   （命中所需轮次/总轮次）；每臂 3 次重复（贪心解码仍有小样本方差）
4. 判定：B 臂命中率 > A 臂且 ≥2/3 次命中 → "策略可注入"成立

## 4. 实验四：修复闭环 v2（衔接原 Phase 1 目标）

仅当实验三命中病灶后才运行：
- 模型 propose_edit（预算内，结构化 schema 不变）
- Weight Editor 应用 → V1-repaired
- 全量评测 + McNemar：与 V0-defect 相比恢复 ≥5pp 且 p<0.10 → S5'
- oracle（V0 原值恢复）与 random-edit 对照臂照常
- **诚实条款**：若实验一就没找到合格缺陷，实验三/四改为在"统计隐形但
  行为有效"的缺陷上运行，并把"诊断协议失败"作为结果报告

## 5. 基础设施修正（先行，半天）

1. `quick_eval` 退役决策用途，仅用于冒烟（审计 F 项证明其无效力）
2. `evaluate.py` 输出增加逐题配对检验（内置 McNemar，杜绝人工算均值）
3. 注入器统一走 `inject_defect_v3.py` 接口，`--select {norm,activity}`
   `--op {zero,scale,lowrank}` `--k N`，密封记录带全参数
4. 激活贡献捕获器（audit_baseline2 的 `capture_contributions`）提为
   `scripts/neuron_activity.py` 公共模块

## 8. 与原 Phase 2 设计的差异说明

原设计（PREREGISTRATION 的 Phase 2 节）直接做"genuine self-editing
on optimization split"。审计证明该前提不成立（连可测缺陷都还没有），
因此 Phase 2 重定位为"传导链修复"——先证明参数干预可以可控地改变行为，
再谈自我改进。这是对项目根本问题的更诚实排序。
