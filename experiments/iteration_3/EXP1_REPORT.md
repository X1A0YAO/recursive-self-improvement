- 日期：2026-11-06 13:45

- 纪律：B2b 教训执行（G2 零行为处方）；评分只依据落盘轨迹

## 一、Gate-3（语义冒烟）：✗ 0/3 —— 实验一按预注册降级

任务：两块 4×2560 真实权重块，一块注入 0.5σ 逐元素扰动，问哪块异常。

- 模型 3 次全答 Y（异常块在 X 侧时全错；位置轮换后仍全错）
- **结论：4B 模型无法通过上下文中的原始数字分辨"被扰动 vs 健康"的权重块**
- 与 Takehi et al. 原文的 L1 层（raw-weight-in-context）边界一致：
  原文该能力也仅在 ≤172K 参数小网络上展示，从未在真实 LLM 张量上成立。
  我们的 4B 实验把这条边界首次量化到了"单块 4×2560 都不行"

按预注册 §1：实验一降级为**读取行为测量**（不测语义理解）。

## 二、G1（固定计划）：完全遵循，读取真实发生

3 次重复逐轮一致（贪心解码）：

- 9 次有效读取（8 计划内 + 1 自由轮），4 个不同张量
- 覆盖层 {0, 1, 18, 35}（计划指定的 0/18/35 + 模型自发加查 L1）
- compare_weights 正确使用（self vs healthy_ref）
- **关键观察**：G1 的 reasoning 里出现真实数据陈述
  （"All compared weights between self and healthy_ref are identical in
  layers 0, 1, 18..."）——与工具返回一致，**有数据支撑的观察报告**
- 计划执行偏差：r8/r11 模型把 report 误写成 propose_edit（schema 混淆），
  但不影响读取行为数据

## 三、G2（自由探索）：幻觉报告——本次实验最重要的发现

3 次重复行为完全一致：

- **round 0 直接输出 report，0 次工具调用**
- 报告内容是编造的："数值范围 -3.5 到 3.5（layers.22 up_proj）、
  行 L2 范数稳定、矩阵良态"——它从未读过任何数据
- 三次的幻觉文本逐字相同（同一先验的确定性采样）

### 定性：这是"观察幻觉"（observation hallucination）

G2 提示只说"自由检查你的权重，然后汇报"。模型的最短路径解是：
直接生成一份"听起来像检查过"的报告。没有固定读取计划的约束，
4B 模型**默认跳过观察**。这与 G1 的对照（强制计划下报告有真实数据）
形成干净的因果对照：**结构约束 > 自主意愿**。

### 与原文的对照

原文的 Astra 在自由 prompt 下能自主设计检查流程（L2/L3 层）。
我们的数据表明该行为在 4B 规模**不存在**：自主探索提示反而触发
幻觉捷径。原文的成功依赖前沿模型的指令遵循与长程规划能力。

## 五、对实验二的直接输入

1. G2 式自由提示**不能**用于实验二诊断（幻觉报告 = 定位 0 信息）
2. 实验二的 G2'（自主探索臂）必须含**最小结构锚**：任务目标里
   "定位缺陷"的强制性本身就是反幻觉约束（诊断任务有外部可验证目标，
   unlike 自由汇报）——这是设计假设，实验二检验它
3. compare_weights 是被自然使用且信息量最高的工具（G1 的真报告来自它）
4. Gate-3 失败 → 实验二里 read_weight 的原始数值展示价值存疑，
   compare 的 diff 统计（0 vs 非 0）是 4B 可用的信息形态
