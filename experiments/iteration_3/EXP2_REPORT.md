## 三、机理综合（实验一+二合并图景）

```
信息形态          4B 可用性        证据
────────────────────────────────────────────
原始数值块        ✗ 无法分辨       Gate-3 0/3（0.5σ 扰动都看不出）
行级 diff (0/非0) △ 看得见但够不着  compare 返回全零（行窗口错过病灶）
聚合统计摘要      △ 读得懂         B2a: 正确锁定投影+层（但不会停）
提案提交          ✗ 全面失败       B2a 0/3, B2b 0/3, 本实验 2/18（均空）
```

**核心结论：4B 模型的自诊瓶颈不在"看哪里"而在三处**
1. **分辨率错配**：有意义的最小单元（行）在 9728 行空间里，8 行/次 × 12 轮 = 0.1% 覆盖
2. **无分层聚合**：缺少"张量→区域→行"的多尺度工具（一次给 252 单元摘要，一次给 8 行原始值，中间断层）
3. **提案悬崖**：与 B 系列一致的系统性失败——证据收集与结论提交之间的转换不发生

## 四、对实验三/四的预注册输入（下一步设计约束）

1. **编辑实验（实验三）的前提不成立**：定位 0 命中 → Agent 编辑臂
   无的放矢。实验三若运行，只能是 oracle 定位 + Agent 修复值
   （即 Phase 2 A2 模式），结果可预期（layer_mean_fill 式保守填充）
2. **RSI（实验四）的可测形态**：与 Phase 2 结论合并——权重通道 RSI
   在 4B + 隐蔽缺陷域的证据链在三重断裂（行为冗余/统计隐形/提案悬崖）
   下无法建立。**诚实结论：本项目范围内 RSI 未成立**，且每一环的
   失败机理已定位并量化
3. 若继续：唯一有信息增量的新实验是**多尺度分层工具**
   （tensor → 64-行块摘要 → 8 行原始值三级钻取），这是 harness
   设计问题而非模型能力问题——可作为 Phase 3b 或移交后续工作
