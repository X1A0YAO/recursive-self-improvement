# 预注册修订 #2：缺陷类型变更（低秩噪声 → 神经元病灶）

- 日期：2026-11-05 01:45
- 触发：两次抽取位置的低秩扰动敏感度扫描均显示行为无感

## 证据（scripts/sigma_scan.py，结果在 logs/ 与本文件）

o_proj @ layer 18（第 1 次抽取）：
  frac=0.30 → logprob Δ+0.013；frac=1.00 → Δ+0.026（~1%）

up_proj @ layer 26（第 2 次抽取）：
  frac=0.30 → Δ+0.008；frac=1.00 → Δ+0.034

行为验证（quick_eval 20 题）：frac=0.30 @ o_proj 得分与 V0 完全一致（0.950 vs 0.950）。

结论：随机 rank-4 低秩扰动即使在 100% 范数能量下也不产生可测量行为退化。
Qwen3-4B 对随机低秩方向极度鲁棒（与文献中 LLM 鲁棒性现象一致）。
继续加大 sigma 将超过 rel_l2=1.0（delta 大于 W 本身），变成全局破坏而非"缺陷"，
违背"可测量但不毁灭"的设计目标。

## 修订后的缺陷定义（第 3 次也是最终定稿）

- 类型：**神经元病灶**——将 layer 26 mlp.up_proj 的 k 个随机行的权重置零
  （即杀死 k 个 MLP 神经元的 up 通路；SwiGLU 下该神经元输出恒为 0）
- 位置：layer 26（第 2 次抽取结果沿用，未重抽，避免挑选）
- k：由敏感度扫描标定（64/128/256 中选首个产生 15-40% 行为退化的值）
- seed：178798052（沿用第 2 次抽取）
- 可逆性：精确可逆（保存被置零行的原值；oracle = 原样恢复）
- 统计可见性：up_proj 的行范数分布将出现 k 个 0 行——
  Agent 的跨层统计（全局 std/l2 变化）与逐行统计（若请求）均可发现

## 为何这不违背盲诊原则

- 标定扫描是实验设计侧操作（确定 k），结果只写入密封记录与预注册文件
- Agent 提示词与工具返回不含任何病灶位置/数量信息
- Agent 需自己决定用什么工具、查哪里
